Уважаемые коллеги, ПО Медстат 2020 уже содержит базу данных годовых отчетов медицинских организаций за 2019 год для проведения межгодовых контролей, осуществлять загрузку данных за 2019 самостоятельно не нужно.

Для установки ПО Медстат на Ваши рабочие места необходимо внимательно изучить презентацию Медстат 2020. Файл запуска программы medstat.exe содержится в папке JOB20.

Файл из папки "arx19" скопировать в директорию "ARX19" (с обязательной заменой файла в директории, где расположена программа Медстат 2019).
