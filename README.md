# Миррор сайта miacso.ru — пакет для переработки

Локальная копия действующего сайта **https://miacso.ru** и извлечённая из него
информация. Визуальная часть (шаблон, CSS, графика оформления) сохранена
исключительно как исходный материал: новый сайт собирается с нуля

## Структура

| Папка / файл | Содержимое |
|---|---|
| `mirror/site/` | HTML-страницы в том виде, в каком их отдаёт сервер (структура папок повторяет URL) |
| `mirror/content/` | Текст каждой страницы в Markdown (заголовок, заголовки, текст, формы, ссылки) |
| `mirror/manifest.jsonl` | По одной JSON-записи на каждый загруженный URL: статус, тип, размер, локальный путь |
| `mirror/inventory.json` | Машиночитаемая сводка: карта сайта, контентная модель, контакты, вложения |
| `mirror/INVENTORY.md` | Отчёт по составу сайта |
| `CRAWL_REPORT.md` | Как устроен обход и что было исправлено |
| `REDESIGN_BRIEF.md` | Бриф на переработку |
| `mirror/BROKEN_LINKS.md` | Битые ссылки и недоступные поддомены |
| `mirror/external_links.json` | Внешние ссылки, сгруппированные по домену |
| `mirror/urls_skipped.json` | URL, отфильтрованные политикой обхода |
| `mirror/files/` | Файлы и вложения (пока пусто) |
| `mirror/doc_text/` | Текст документов (пока пусто) |
| `_cache/` | Кэш HTTP-ответов, позволяет докачивать без повторных запросов |
| `tools/` | Скрипты обхода и извлечения |

## Главные документы

* `REDESIGN_BRIEF.md` — бриф на переработку: что за сайт, какие разделы,
  какие типы контента, требования к новой вёрстке.
* `CRAWL_REPORT.md` — как собиралась копия, какие найдены дефекты.
* `mirror/INVENTORY.md` — полная карта сайта и контентная модель.

## Скрипты

```powershell
# Обход сайта (докачивает недостающее, опираясь на манифест и состояние)
python tools/crawl.py

# Начать обход заново
python tools/crawl.py --seed https://miacso.ru/home

# Только страницы, без файлов
python tools/crawl.py --no-assets

# Пересобрать очередь обхода по уже скачанным страницам (после сбоя)
python tools/rebuild_state.py

# Извлечь текст из документов
python tools/doctext.py

# Собрать отчёт
python tools/inventory.py

# Проверки
python test_parser.py     # разбор HTML
python test_paths.py      # отображение URL -> путь на диске
```

## Как устроен обход

* `tools/fetchlib.py` — HTTP-клиент: ограничение частоты (0.6 с между
  запросами), повторные попытки, дисковый кэш.
* `tools/htmllib.py` — разбор HTML на стандартной библиотеке: ссылки, ресурсы,
  формы, заголовки, видимый текст. Отдельно обрабатывается BOM в начале
  страниц (без этого не читался `<title>`).
* `tools/crawl.py` — обход в ширину. Внешние домены не скачиваются, а
  фиксируются в `external_links.json`. Расширения-скрипты (`.php`, `.html`)
  считаются страницами, а не файлами.
* `tools/pdftext.py` — извлечение текста из PDF: потоки FlateDecode,
  кодировка WinAnsi/CP1251 и карты `/ToUnicode` (Identity-H).
* `tools/doctext.py` — текст из PDF, DOCX, XLSX, PPTX, ODT/ODS/ODP, TXT, CSV.

## Что важно знать про исходный сайт

* CMS — **Joomla** (PHP 7.4), шаблон `new_shablon_osnov_5_16_norm` (Artisteer).
* Корень `https://miacso.ru/` отдаёт **404** — все разделы живут по путям
  (`/home`, `/novosti`, ...). Главная страница сайта фактически `/home`.
* `robots.txt` и `sitemap.xml` отсутствуют.
* Вёрстка не семантична: заголовок страницы — `<h2>`, блоки свёрстаны на
  `div`/`table`, есть MooTools и устаревшие скрипты.
* На страницах есть форма поиска (POST на `/index.php`) и счётчик посещений
  (`coalawebtraffic`).
