# Бриф на переработку сайта МИАЦ Свердловской области

Документ описывает исходное состояние сайта **https://miacso.ru** и то, что
нужно сохранить при полной пересборке визуальной части.

---

## 1. Что представляет собой текущий сайт

| Параметр | Значение |
|---|---|
| CMS | Joomla (PHP 7.4.33), шаблон `new_shablon_osnov_5_16_norm` |
| Генератор шаблона | Artisteer (классы `art-*`, `art-sheet`, `art-block`) |
| Кодировка | UTF-8 **с BOM** |
| robots.txt / sitemap.xml | отсутствуют |
| Корень `/` | отдаёт **404**; фактическая главная — `/home` |
| Поиск | форма POST на `/index.php` (`searchword`, `task`, `option`) |
| Счётчик | `coalawebtraffic` (вывод в `#cwtraffic1`) |
| Сторонние виджеты | ПОС «Госуслуги» (`pos.gosuslugi.ru/bin/script.min.js`) |

### Технические особенности вёрстки

* Страница свёрстана на `div` с классами Artisteer, а не на семантических
  тегах; `main`/`aside` отсутствуют, `header`/`nav`/`footer` есть.
* Заголовок страницы — `<h2>`, а не `<h1>`; на главной всего три заголовка
  (`h2` «О центре», `h3` «!!!», `h3` «Госуслуги»).
* Каскад: `template.css`, `template.ie7.css`, `template.responsive.css`,
  `system.css`, `general.css` + CSS виджетов.
* MooTools (`mootools-core`, `mootools-more`, `core.js`), jQuery 1.x
  (в `libraries/videobox`), `html5shiv` с внешнего CDN Google Code.
* В `viewport` жёстко задано `maximum-scale=1.0, user-scalable=no` —
  блокирует масштабирование (проблема доступности).
* Внутренние ссылки встречаются как в «человеческом» виде (`/home/kontakty`),
  так и в виде `index.php/home/kontakty` и `index.php?option=...` — это надо
  нормализовать при переработке.

## 3. Типы контента, которые должны поддерживаться

1. **Статическая страница** — заголовок + текстовые блоки, таблицы.
2. **Список новостей** + **карточка новости** (дата, заголовок, текст).
3. **Каталог документов** — список файлов с типами (PDF, DOCX, XLSX, ODT)
   и, часто, с указанием редакции/года.
4. **Каталог информационных систем** — карточка системы с описанием,
   инструкциями и файлами.
5. **Календарь событий** (ВКС) — месячный список с датами.
6. **Контакты** — телефоны, e-mail, адрес, реквизиты, схема проезда.
7. **Вакансии** — список вакансий.
8. **Закупки** — список закупок со ссылками на документы.
9. **Страница-заглушка** — «сайт в стадии актуализации» (сейчас на главной).
10. **Поиск** по сайту.

## 4. Требования к новой визуальной части

* Пересобрать с нуля: HTML-структуру, CSS, JS, графику оформления.
* Семантическая разметка: один `<h1>` на страницу, `header`/`nav`/`main`/
  `footer`, `article` для новостей и документов.
* Адаптивность без запрета масштабирования; `viewport` без `maximum-scale`.
* Доступность: контраст, навигация с клавиатуры, alt у изображений,
  корректная иерархия заголовков.
* Отказ от MooTools, jQuery 1.x и `html5shiv` с Google Code CDN.
* Сохранить все URL или настроить 301-редиректы со старых адресов,
  включая варианты `index.php/...`.
* Единый механизм выдачи файлов-вложений с указанием типа и размера.
